Settings

A face length rarely divides evenly into whole roll widths, so there's always some leftover — normally spread thinly across every seam as extra overlap above the minimum. Turn this on and every seam sits at exactly the minimum overlap instead, with the leftover pushed into the face length itself (rounded up to whatever whole strips at that overlap actually cover) — the field updates to the real as-built length. Only applies to manually-typed face lengths, not DXF extents/benched/battered lifts, which are already bound to a real surveyed boundary. Applies to whichever product a lift uses.

Which end of the face strip 1 is numbered/packed from — set this to Right when the right-hand tie-in is the critical reference point on site, so strip 1 is the first one rolled out from there. On its own this just mirrors today's layout (same overlap-spreading, same strip positions) so it counts from the opposite end — nothing physically moves. For DXF extents/benched/battered lifts this is which end of the already-detected face strip 1 starts against (use the "Face" picker on the Cut Plan tab to change which edge is treated as the face in the first place); for a manually-typed length, every strip is the same depth anyway so this only affects numbering/roll order, not the layout.

Every strip is a full, uncut roll width, working in from the side above — strip 1 is always flush against that side. Every seam, including the last, sits at exactly the minimum overlap — never more. Whatever's left over once no more full-width strips fit isn't turned into extra overlap or a narrower cut strip; the last strip just runs past the far edge of the design line by that amount, same as any other roll off-cut. Unlike "Extend face length" above, this works on DXF extents/benched/battered lifts too, not just manually-typed lengths. Takes priority over "Extend face length" if both are turned on.

A stitch patch covers a pocket of true boundary sitting past a gap the main strip's single straight cut can't reach in one piece — normally its own small supplementary piece, cut and installed separately from the main strip beside it. Turn this on and every strip becomes one continuous piece instead: its cut length stretches straight through any such gap out to the true far reach, so nothing needs a second cut or a separate patch. Uses more material at the gap (it's buried under the strip rather than trimmed to it), but every strip in every diagram, list, and roll count is a single, ordinary piece — nothing marked as a stitch anywhere.

The Roll schedule packs strips onto the fewest possible rolls by pooling every lift together — lowest waste, but any one roll can end up with pieces from lifts scattered right across the job. Set a lift count here (e.g. 3) to only ever share a roll between that many adjacent lifts — a bit more offcut, but each roll stays close to where it's actually used. Leave blank to pool everything. Different products are always packed onto separate rolls regardless of this setting — they're physically different rolls.

Base level is the RL fill started from, below the lowest lift — needed to work out that lift's own fill volume (every lift above it uses the RL gap to the lift below, so only the bottom one needs this). Leave blank if you don't need fill volumes, or don't mind the bottom lift missing from the total.

How the numbers are calculated
Strip count
Fewest full-width strips that still meet the minimum overlap: n = ceil((L − omin) / (w − omin)), for face length L and roll width w.
Actual overlap
The minimum-strip overlap is then spread evenly across every seam: o = (n·w − L) / (n − 1) — always ≥ the spec minimum, never a trimmed strip.
Roll off-cut
Strips are pooled across all lifts that share the same embedment length, then packed into 1×roll-length pieces (floor(roll length ÷ embedment)) to minimise leftover per roll.
Battered surface levels
Each target RL slices the surface into a cross-section, and the whole outline becomes one lift's extents — a fill sequence, one horizontal grid layer per level reaching out to the cut in every direction, not a separate layer per wall. If more than one closed loop comes back from a slice, the largest by area is taken as the real excavation outline. If the top of the surface is uneven, part of the boundary can already have ended (daylighted into the original ground) below that RL — the slice comes back open rather than closed, and the gap is closed with a straight line between its two ends purely so the boundary math has a defined "inside."

    Extents

    Upload one DXF containing a closed polyline per lift — the outer plan-view extents each strip has to fit inside. The tool finds the longest edge as the face and clips every strip against the boundary, so strips near a taper come back shorter with an exact cut length. Uploading a second file for a different product at the same RLs adds it alongside the first instead of replacing it — pick which product this file is for below first.

    Benched

    Upload the raw cut surface as a triangulated mesh and the tool will find the flat bench at each lift's RL itself, matched onto the lift rows already in the table — no pre-built extents needed. DXF (3DFACE) or LandXML (Civil 3D's native surface export) both work.

    Battered

    Upload a full excavation surface (already dug, sloped sides, no pre-existing lift rows needed) and the tool builds the rows itself: set a spacing below, then it reads the surface's own elevation range, slices it at every RL that fits, and lays one horizontal grid layer per lift out to the cut in every direction — a fill sequence, not one row per wall.

    Leave Start RL and Count blank to use the whole surface (lowest point up to highest, in steps of Spacing) — set either one to override just that end.
